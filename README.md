# Task Manager

> Em desenvolvimento — projeto de longo prazo da Programming Academy.

Gerenciador de tarefas construído gradualmente em Python, com evolução planejada para persistência local, testes, banco de dados, API REST e interface web.

## Objetivo

Desenvolver uma aplicação completa enquanto pratico fundamentos de programação e engenharia de software, com foco em código compreensível, evolução incremental e decisões técnicas justificáveis.

## Status atual

**Milestone 1 — CLI básica**

Em andamento:
- menu principal;
- adicionar tarefa;
- listar tarefas;
- concluir tarefa;
- remover tarefa.

## Roadmap

- CLI em Python
- Persistência em JSON
- Modularização e tratamento de erros
- Testes automatizados
- SQLite e SQL
- API REST
- HTML/CSS/JavaScript
- Integração frontend/backend
- Revisão final para portfólio
